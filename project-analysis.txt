Locale: Spanish (es)

2. DESCRIPCIÓN DEL SISTEMA
--------------------------
Sistema de gestión de órdenes con notificaciones mediante códigos QR que permite:
- Generación de órdenes con códigos QR únicos
- Escaneo de QR con app móvil Flutter
- Notificaciones push al dispositivo móvil del cliente
- Gestión multi-tenant con panel SuperAdmin
- Procesamiento de pagos (Stripe/MercadoPago)
- Sistema de tickets de soporte
- Chat en tiempo real

3. ARQUITECTURA
--------------------------
- Multi-tenant SaaS
- Autenticación multi-guard (web, business, superadmin, API)
- API RESTful v1 con Laravel Sanctum
- Frontend: Livewire + Blade Templates
- Base de Datos: MySQL (17 tablas principales)
- Integraciones: Firebase (Push), Stripe, MercadoPago, Google Maps
